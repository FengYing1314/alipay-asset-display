# 使用指南

本指南面向已具备 LSPosed 环境的 Android 用户。模块为已适配的支付宝页面设置本机显示金额，不改变真实资产、账户数据、网络响应或支付能力。

当前提供 `v0.1.0` 开发预发布 Debug 包，尚非稳定版。支持条件为 Android 9（API 28）及以上、具备 API 102 和远程配置能力的 LSPosed，以及支付宝 `12.12.36.8000`（版本代码 `212370`）。部分页面还要求匹配已适配的资源版本和结构；应用版本相同不代表所有页面一定适配。

新包名 APK 已完成本地构建检查，尚未完成新包名的实机验收。具体记录见 [验证与诊断](verification.md)。

## 下载与校验

从 [v0.1.0 预发布页](https://github.com/FengYing1314/alipay-asset-display/releases/tag/v0.1.0) 下载：

- `alipay-asset-display-v0.1.0-debug.apk`：安装包。
- `SHA256SUMS`：安装包的 SHA-256 校验值。

在提供 `sha256sum` 命令的系统中，将两个文件放在同一目录后运行：

```bash
sha256sum -c SHA256SUMS
```

确认 APK 对应结果为 `OK`。校验值用于确认文件完整性，不代表 Android 签名相同，也不能证明该包能覆盖已有安装。升级前先阅读 [更新与签名](#更新与签名)。

## 安装与启用

1. 安装下载的 APK，按 Android 系统提示允许本次安装。
2. 在 LSPosed 中启用“支付宝资产显示修改”，作用域勾选支付宝。
3. 完全退出并重新打开支付宝，使模块在新进程中加载。仅返回桌面不一定结束原进程。
4. 从应用列表打开模块设置，确认“框架连接”显示已连接及 API 102。
5. 按下节填写四项金额，打开“启用金额显示”，点击“保存配置”。
6. 重新进入目标页面，确认显示、隐藏恢复和非目标字段符合预期。

框架连接说明设置页可以访问框架，不能据此确认支付宝作用域正确或目标页面已应用。旧包名用户请先按 [迁移步骤](#从旧包名迁移) 停用旧模块，避免两个模块同时生效。

## 设置显示金额

四项金额独立保存，总资产不会自动求和。以下仅为合成示例：

| 设置项 | 示例输入 | 保存后的值 | 主要显示位置                               |
| ------ | -------: | ---------: | ------------------------------------------ |
| 余额   | `1234.5` |  `1234.50` | 总资产详情、余额详情的可用余额主金额       |
| 余额宝 |   `6789` |  `6789.00` | 理财首页、总资产详情、余额宝详情顶部总金额 |
| 基金   | `234.56` |   `234.56` | 理财首页、总资产详情、基金持有页顶部汇总   |
| 总资产 |   `9000` |  `9000.00` | 理财首页、总资产详情                       |

金额范围为 `0`～`999999999.99`，整数部分最多九位，小数部分最多两位。使用普通数字，不输入千分位逗号、正负号、科学计数法或货币符号；例如输入 `1234.50`，不要输入 `1,234.50`。空白金额不能保存，也不会自动按零处理。

模块不修改基金明细、收益、利率、份额、冻结额或余额宝独立可用金额。配置允许的最大金额不代表所有屏幕都能完整显示；余额详情中，无法放入已识别单行布局的金额可能暂缓显示，可改用较短的合成金额验证。

修改输入或开关后，需要点击“保存配置”：

- “尚未保存”表示当前内容仅是本机草稿，退出再打开设置后会保留未保存的输入。
- “配置保存成功”表示框架确认写入配置，不表示目标页面已完成应用。
- 保存成功后重新进入目标页面检查结果。隐藏金额时，隐藏状态优先；模块不会为了显示配置值而取消隐藏。

## 停用与恢复

1. 在模块设置关闭“启用金额显示”。
2. 确认四项金额仍为合法格式，再点击“保存配置”。当前保存流程也会校验停用时的金额；如有空白或非法草稿，先修正后保存。
3. 确认停用配置保存成功，然后重新进入目标页面检查恢复结果。

停用不清空四项金额，之后可重新开启并保存。保存成功仍不能代替页面恢复检查。显隐切换、页面身份变化或原文失效后，模块不会回放缓存数字；页面可能暂时显示 `****`、空白主金额或等待宿主重绘，可刷新或退出后重新进入页面。

若设置页无法连接框架，可在 LSPosed 中停用模块，再完全退出并重新打开支付宝。关闭金额显示不会自动关闭结构诊断；如曾开启诊断，还需在“高级设置”关闭并保存。

## 更新与签名

当前 Releases 和 Actions 提供的均为开发 Debug 包。不同构建环境或 CI 运行可能使用不同 Debug 签名，不能保证互相覆盖安装。

更新前自行记录四项显示金额及开关状态，并核对目标包名 `io.github.fengying.alipaydisplay`。若 Android 拒绝覆盖安装，先核对包名、版本与签名，不要直接把安装失败当作模块运行故障。

只有包名相同且签名兼容时，才可按 Android 允许的方式覆盖更新。若需要卸载后重新安装，应先记录配置；不要假设本机草稿或框架配置会保留或自动恢复。重新安装后检查模块启用状态、支付宝作用域和四项金额，再完全退出并重新打开支付宝验证。

项目尚未提供设置导入、导出或自动迁移功能。下载校验通过也不会解决签名不兼容问题。

## 从旧包名迁移

旧包名为 `io.github.fengying.alipaydisplaydemo`，当前包名为 `io.github.fengying.alipaydisplay`。Android 将两者视作独立应用；新 APK 不会覆盖旧应用，本机草稿和 LSPosed 模块配置不会自动迁移。

1. 自行记录旧模块的四项显示金额及开关状态。
2. 在 LSPosed 中停用旧包名模块。
3. 安装新包名 APK，启用“支付宝资产显示修改”，作用域勾选支付宝。
4. 打开新模块设置，确认框架连接，重新填写金额及开关状态并保存。
5. 完全退出并重新打开支付宝，逐页验证显示与停用恢复。

旧模块是否卸载由使用者自行决定；迁移过程中保持旧模块停用，避免两个模块同时生效。新包名当前验证范围见 [包名迁移验证边界](verification.md#包名迁移验证边界2026-11-01)。

## 获取 Actions 构建包

需要较新的开发构建时，可打开 [Checks 工作流](https://github.com/FengYing1314/alipay-asset-display/actions/workflows/ci.yml)：

1. 选择目标提交对应的一次成功运行。
2. 在 **Artifacts** 区域下载 `alipay-asset-display-debug`。
3. 解压后取得 `app-debug.apk`，按 [安装与启用](#安装与启用) 操作。

下载 Artifacts 需要登录 GitHub，产物保留 7 天。过期后选择更新的成功运行，或按 [开发与构建](../README.md#开发与构建) 自行构建。反馈问题时记录该次运行链接或提交版本。

Actions 成功说明自动检查和构建通过，不代表实际注入或手机验证通过。其 Debug 签名同样适用 [更新与签名](#更新与签名) 中的限制。

## 常见问题

### 设置页未连接框架或提示不支持

先确认 LSPosed 已启用当前包名的模块，再重新打开设置。框架必须同时支持 API 102 和远程配置能力；仅安装 APK 或使用不兼容框架不能保存配置。提示读取框架失败时，恢复框架连接后重新打开设置。

### 保存失败或未能确认保存结果

金额格式错误时，修正提示的输入后重试；停用时也需要合法金额。框架断线或写入结果无法确认时，当前输入会保留，恢复连接后重试。不要把“尚未保存”的草稿当作已应用配置。

### 保存成功，但支付宝没有变化

按以下顺序核对：

1. “启用金额显示”是否打开并已保存。
2. LSPosed 是否启用了当前模块，作用域是否勾选支付宝。
3. 启用或更新模块后，是否完全退出并重新打开支付宝。
4. 支付宝是否为 `12.12.36.8000`（版本代码 `212370`）。
5. 当前页面和字段是否在 [支持范围](../README.md#功能与边界) 内，金额是否处于隐藏状态。

以上条件符合后仍无变化，可重新进入目标页面。设置页目前不能确认具体页面是否已应用；请按 [反馈问题](#反馈问题) 提供最小复现信息。

### 支付宝版本相同，某个页面仍不生效

支付宝页面资源可以独立变化。当前适配还核对特定资源版本、路由和页面结构；未知版本或不能唯一识别的结构保持宿主原样。具体条件见 [兼容条件](verification.md#兼容条件)。请报告受影响页面和必要操作，不修改版本门禁来强行应用。

### 隐藏后再显示，出现星号、空白或暂时未恢复

模块优先尊重隐藏状态。隐藏、重绑或页面身份变化后，需要宿主重新提供可信的新内容，不能复用隐藏前的数字。可刷新或重新进入页面；停用后仍有残留显示时也先让宿主重绘。持续复现时记录切换顺序，并说明是否修改配置、离页或退到后台。

### 如何开启诊断

在“高级设置”开启“采集页面结构（诊断）”并保存，重现问题后按 [结构诊断](verification.md#结构诊断) 查看 `AlipayDisplayDiag` 固定标签。诊断默认关闭，排查结束后关闭并保存。诊断状态不能单独证明所有页面或屏幕刷新帧均已正确应用。

## 反馈问题

通过 [问题报告](https://github.com/FengYing1314/alipay-asset-display/issues/new?template=bug_report.yml) 提供：

- 模块版本；Actions 构建另附运行链接或提交版本。
- Android、支付宝和 LSPosed/API 版本。
- 受影响页面、开关状态和最短复现步骤。
- 使用合成金额描述预期与实际结果；必要时附固定分类、计数、布尔状态或构建错误摘要。

不要上传真实金额、账户、基金名称、设备标识、完整 URL、查询参数、原始截图、设备转储、签名材料或未经筛选的系统日志。确需截图时，先遮挡所有相关个人信息并确认脱敏结果。

涉及安全或隐私的问题，按 [安全政策](../SECURITY.md) 私密报告，不在公开 Issue 中披露敏感细节。
