## 手机验证

1. 安装 APK，在 LSPosed 启用“支付宝资产显示修改”，作用域勾选支付宝。
2. 完全退出并重新打开支付宝，使新模块在进程启动时加载。
3. 打开模块设置，确认连接 API 102 框架；填写四个显示金额，打开金额显示，保存配置。
4. 进入理财首页，检查三处金额及朗读与对应配置一致，收益等其他字段不变。
5. 分别验证隐藏、恢复、下拉刷新、切换页面、退后台再返回、修改配置和停用。检查隐藏后没有旧配置数字重现；恢复后等待宿主新金额再应用。

设置中的“保存成功”只说明框架确认配置写入。当前无法从设置页确认目标页面是否已应用。重绑、隐藏、身份变更后若原文不再可信，模块不回放旧数字；可能显示 `****` 或等待宿主重新公开原控件，需要时请刷新或重新进入页面。

基金适配保留宿主数字子树，使用独立的显示节点。身份失效时只清私有会话，不在未知文档回写；残留显示节点或隐藏样式可能需要宿主重绘、重新进入页面清除。当前配置的单行及裁切检查不代表最大九位整数在所有屏幕上均已完成视觉验收。

## 结构诊断

为继续核对页面结构，可在设置开启“采集页面结构（诊断）”并保存。然后进入对应详情页，通过以下命令读取固定日志标签：

```bash
adb -s "$ANDROID_SERIAL" logcat -v brief -s AlipayDisplayDiag:I '*:S'
```

日志仅输出白名单结构标签、通用名称、层级、命令类型摘要及数字/掩码/隐藏状态。金额、账户、基金名称、URL 及查询参数不写日志或文件；宿主金额仅用于页面内存中的归属、显隐及布局检查。

Web 探针使用实际自定义 WebView 的只读 `evaluateJavascript`，每次进入或原生导航后最多三轮采样、每轮最多 200 个 DOM 节点，截断会明确标记。Cube 诊断仅在严格归属内检查已知绘制结构并输出分类结果。结构诊断和金额显示分别管理，诊断开关不控制金额功能。

开启诊断时，基金会话还会在同一文档代次最多读取六次固定布尔状态；不消费待处理事件、不重绑定或修改 DOM。离页、文档或身份变化会取消后续读取。

页面退出、原生导航、暂停、销毁和活动页面对象/规范化路径变化会使旧诊断回调失效。只读诊断仍不能单独区分所有同址刷新。Web 显示另外使用文档 nonce、完整导航内存比较和局部 DOM 监听，文本与 aria 分别记录归属及新鲜度；隐藏后不回放旧数字。同文档的显示会话保留到销毁，暂停时延后 Java 检查，显隐观察继续有效。

## 首次显示与无闪现验证范围

原生三处金额在 preDraw 同步检查；布局尚未更新时最多重排两次，精确金额控件的 onDraw 仍会阻止不安全数字绘制。会话留到 onStop，避免退出动画提前恢复原文。余额页在实际 onDraw 中使用金额副本，诊断区分替换、暂缓与未覆盖的已知金额绘制。

余额从后台或设置返回时会使已确认的视图重画，避免沿用切换前的 RenderNode。配置仍在后台读取；请求代次会拒绝过时快照。读取期间只对严格识别的主金额临时保护，完整新快照到达后重画，不在主线程同步读取远端配置。

三个已知 Web 页面在完整金额应用后，还须收到同代次的真实 SDK visual 回调才放行绘制。等待期间使用透明图层保持子树绘制调度，不改 View 属性。单次门控最多五秒，重试不续期；超时、未知归属或回调失败明确标为 `unproven`。回调桥由本地源码构建为单类 DEX，仅在内存加载；SDK 编译桩不打包。

已有实机基线完成了绘制链路取证：原生金额及退出阶段、余额两套结构的首屏与页面返回/停用重启用，以及三个 Web 页的真实 visual 回调。余额串行检查记录 8 次已知主金额绘制：5 次配置替换、3 次配置读取期间的空主金额保护，均正常完成并归还原对象，未覆盖计数为 0；其它命令引用保持不变。最终诊断已关闭，金额显示保持开启，四项金额配置未变。此结果只覆盖已测版本、结构、配置和操作场景，不等于所有物理刷新帧的逐像素证明。未保存原始截图或视频；设备的纯内存视频流未验证成功，因此不把录屏检查计为通过。
